# 界面规则（现行）

片库后台的界面约定。改界面前先读这一页；它与代码里的注释是同一套口径。

## 组件分工

| 场景 | 用什么 |
|---|---|
| 图片型列表（媒体库、片单） | `RecordGrid`（网格卡，手机 2 列） |
| 商城商品（全部商品 / 店铺） | `ProductTile`（封面 + 名称 + 价格 + 销量库存 + 购买键） |
| 信息型列表（订单、资金、榜单、用户、线路、悄悄话、直播、我的店铺商品） | `RecordRow`（一行一条；手机单列堆叠） |
| 待办型列表（求片） | `RecordRow multi`（桌面多列、三键整行） |
| 列表外壳（四态 + 触底加载） | `ListSection`：出错 / 加载（同形骨架）/ 空 / 内容 + 哨兵 |
| 详情页头 | `DetailHead` + `DetailStats`（只放文字，不放图） |
| 状态徽标 | `Badge`（六档色调 `ok/wait/run/warn/off/danger`） |
| 搜索框状态 | `useSearchTerm`（本地即时 + 防抖写回 URL） |
| 数值列 | `RecordRow` 的 `value`（等宽、右对齐，跨行可比） |

不要再引入第五种列表实现，也不要给列表套外层容器（卡片自带边框）。

## 卡片约定

- 封面：影片 2:3、片单 16:9、商品/频道/头像方图；没有图时给占位（媒体位一条淡横杠，人显示首字）
- 字段：只放定长信息（类型、年份、季集）；变长信息进 facts 或右侧数值列
- 0 值不渲染（`0 部`、`0 订阅`、`销量 0` 都不显示）
- 类型「电影 / 剧集」是纯文字；其它标注（官方、我的、院线…）同样纯文字；**状态**才用 `Badge`
- 动作：统一落在右侧、垂直居中；只有待办型（求片）把动作铺成整行三键
- 手机：动作回到底部整行右对齐；触控目标 ≥32px

## 布局与间距

- 令牌见 `src/styles/tokens.css`：`--sp-*` 间距、`--text-xs/sm/body` 字号、`--r-card/--r-item/--r-chip` 圆角、`--gap-card` 块间距
- 页面块之间 18px；工具栏与列表之间 18px；网格/行卡的内部间距用 `gap`，不要再叠兄弟 margin
- 断点：1240 / 980（详情页两栏折叠）/ 900 / 600（手机档 ≤600，平板档 ≤900）
- 手机：抽屉导航（Esc 关闭 + 滚动锁），页头工具把次要项折进「更多」

## 写操作

- 每个异步写操作必须接 `isPending` 禁用，危险操作要 `confirmDialog`
- 文案不承诺做不到的事（例如「可在回收站恢复」必须真的能恢复）
- 不写面向开发者的说明（接口行为、缓存策略、内部字段名）

## 时间与空值

- **时间**：活动类（最后使用、更新时间）用 `formatRelative`（刚刚 / N 小时前）；
  身份与期限类（注册、加入、到期、上下架日）用 `formatDate`（`YYYY-MM-DD`，必须带年份）；
  其余精确到分钟用 `formatDateTime`
- **空值**：缺值一律 `—`；只有「状态本身有意义」时才用文字（`未打款`、`已售罄`、`无备注`不显示）

## 数据与分页

- 全站无分页器：`usePagedInfinite` + `InfiniteSentinel`，滚到底续页
- 每页条数固定 `PAGE_SIZE = 20`（URL 里不再有 `page_size`）
- 筛选/排序条件必须进 `resetKey`，否则切换后列表还是旧结果
