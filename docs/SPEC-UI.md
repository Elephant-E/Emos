# UI 规范

> 来自四次审查与若干次返工的结论。写新页面前先读这一页，不要重新发明间距。

## 1. 栅格与间距

| 位置 | 值 |
|---|---|
| 页面左右内边距 | 40px（内容宽 1060 @1440） |
| 卡片内边距 | 24px，四边一致 |
| 表格单元格 | 上下 7px，左右 20px |
| 卡片间距 | 18px |
| 堆叠间距 | `--stack: 12px` |

**不要写死行高**（28/52 这类）。行高由内容决定，对齐靠栅格结构。

## 2. 卡片结构

```
.card
├ .card-head        24px 高：左标题 + 右动作
├ .card-body        margin-top: var(--stack)
│  └ .card-note     说明 / 空态 / 失败，12.5px --fg-3
└

.card--stat         三行 auto + row-gap --stack
├ .stat__label
├ .stat__value      42px / line-height 1 / tabular-nums
└ .stat__delta      12.5px --fg-3
```

规则：

- 卡片里**不许再套卡片**。状态块（Loading/Empty/Error）放进卡片时传 `bare`。
- 表格放进卡片时不会有额外底色；`thead` 默认透明，只有页面级 `.table-card` 的粘性表头有底色。

## 3. 尾部动作对齐（墨迹，不是盒子）

行内动作要和标题**墨迹对齐**，不是盒子对齐。否则按钮自身的 padding 会叠在卡片 padding 上，右侧比左侧多缩 13px。

| 场景 | 做法 |
|---|---|
| 卡片头部文字动作 | `padding: 0`、无边框底色，20px 高，hover 只变色 |
| 图标按钮（26/28 盒） | `margin-right: -6px`（抵消 `(盒−图标)/2`） |
| 表格最后一列文字按钮 | `padding: 0`，单元格右内边距 20px |

已验证：概览签到卡左 25px / 右 25px；表格末列文字按钮 21px（1px 为字形侧边距）。

## 4. 交互状态

- **hover 只改前景颜色**。不铺底色、不位移、不加阴影。
- 加载态只留骨架，不同时显示"正在读取"文案。
- 说"取不到"的时候不要显示成 0——用 `—` 或一句人话。
- 写操作失败必须说清原因（全局 `MutationCache.onError` 已兜底，带状态码）。

## 5. 数字与排版

- 所有数字 `font-variant-numeric: tabular-nums`。
- 统计值 42px、行高 1、单位 17px `--fg-3`。
- 文字重要度阶梯：`--fg` / `--fg-2` / `--fg-3` / `--fg-4`，全部 ≥4.5:1；`--fg-5` 只用于图标与分隔线。
- 中文标题字距 `-0.01em`（不要 `-0.03em`，笔画会粘连）。

## 6. 动效

| 场景 | 规格 |
|---|---|
| 路由切换 | `page-in` 180ms 淡入 + 滚动复位 |
| 弹窗出现 | `modal-in` 160ms，`translateY(6px)` + 轻微缩放 |
| 进度 | `transform: scaleX()`，不要动 `width` |
| toast | 140ms 淡入上移 |

禁止：回弹/弹性曲线、逐行错峰淡入、卡片 hover 位移、数字滚动。全部尊重 `prefers-reduced-motion`。

## 7. 文案

- 动作名即结果名（"发布" → "已发布"）。
- 空态给下一步，不给情绪："还没有片单，建一个把想看的攒起来～"
- 删除要说清后果与可否恢复；**不要承诺不存在的功能**（例如"可从回收处恢复"而回收站没做）。
- 问候类文案按天轮换，避免每天看到同一句。
