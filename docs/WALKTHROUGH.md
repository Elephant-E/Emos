# 真机走查清单

> 你现在能连 `emos.club`，这 15 步点完，比我猜哪里有问题高效得多。
> 每步都写了「应该看到什么」，不对就截图给我。

## 准备

```bash
npm run dev            # http://localhost:5273
```

`.env.development` 现在是 `VITE_MOCK=0`、`VITE_API_ORIGIN=https://emos.club`。
首次进 `/login` 粘贴 token。

---

## A. 读（只验证取数与渲染）

1. **概览** — 签到卡显示「今天已签 N 天」或「立即签到」；胡萝卜、槽位、上传量都有数；「继续观看」有进度条；「我的近况」有本周微条或「本周还没有观看记录」。
2. **媒体库** — 顶部显示 20 万+ 部；翻到第 2 页、改成 100/页；搜「西部」应出现相关结果；点任意一行进详情。
3. **影片详情** — 季切换器可横向滚动；选中某季时，集列表只显示该季（不应出现 01、01、01 重复）；右侧资源与字幕跟随集变化。
4. **片单** — 「我创建的」8 个、每行有「删除」；「全部」260 个、他人在「操作」列显示「—」。
5. **片单详情** — 若你不是维护者，顶部应出现「只能查看」的说明。
6. **回收站** — 资源 Tab 36 万条、影片 Tab 160 条；他人上传的资源「恢复」列显示「—」。
7. **音乐** — 歌曲 52 万条、切专辑（14 万）、切歌手；点歌曲进详情看歌词与资源。
8. **直播** — 77 个频道；点一行展开该频道的源列表。
9. **账号** — 资料页权限四项（观影/上传/下载/槽位）；邀请页名额显示 **∞ 不限**。

## B. 写（会产生真实副作用，按需选做）

10. **签到** — 概览点「立即签到」→ toast 提示 +N，卡片变「今天已签」。重复点应被禁用。
11. **修改笔名** — 账号页改名 → 保存 → 刷新后侧栏和页头都变。
12. **收藏一首歌** — 音乐详情点收藏 → toast；再点一次应切换。
13. **加片单再移出** — 片单详情「添加影片」搜一部 → 加入 → 出现在列表 → 移出（确认框）。
14. **认领求片** — 求片页对「求片中」的行点认领 → toast + 状态变「已认领」，行内出现「去上传」。
15. **商品上下架** — 商城点「下架」→ 状态变已下架；再点「上架」恢复。

## C. 需要留意的失败点

| 现象 | 可能原因 |
|---|---|
| 某页一直骨架屏 | 该接口慢（ban/list 5–11s、stats 11s），或返回 422 |
| 操作后没反应、也没 toast | 该写操作没有 onSuccess 文案（报给我，我补） |
| 数字显示 0 但实际有数据 | 布尔参数没按 1/0 传（已全局修，若复现说明还有漏网） |
| 图片大面积空白 | `image.theotherdb.org` 在我这边不可达，你那边应该正常 |

## D. 已知不可用（不是 bug）

- **支付页**：`/api/pay/base` 返回 404，这个实例没部署支付模块。
- **用户详情的余额/观影/注册时间**：`/api/pay/getUserInfo` 需要服务商身份，当前账号 403。
- **红包/抽奖/投票/基金/悄悄话/影院**：机器人在群里用，没做后台界面。
