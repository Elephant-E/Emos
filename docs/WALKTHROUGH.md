# 真机走查清单

> 真机环境为 `emos.best`。下列 23 步覆盖读与写两条链路，每步标注预期结果。

## 准备

```bash
npm run dev            # http://localhost:5273
```

`.env.development` 当前是 `VITE_MOCK=0`、`VITE_API_ORIGIN=https://emos.best`。
首次进 `/login` 粘贴 token。

---

## A. 读（只验证取数与渲染）

1. **概览** — 签到卡显示「今天已签 N 天」或「签到」；胡萝卜、槽位、上传量都有数；「继续观看」有进度条；「我的近况」有本周微条或「本周还没有观看记录」。
2. **媒体库** — 顶部显示 20 万+ 部；翻到第 2 页、改成 100/页；搜「西部」应出现相关结果；点任意一行进详情。
3. **影片详情** — 季切换器可横向滚动；选中某季时，集列表只显示该季（不应出现 01、01、01 重复）；右侧资源与字幕跟随集变化。
4. **片单** — 「我创建的」8 个、每行有「删除」；「全部」260 个、他人在「操作」列显示「—」。
5. **片单详情** — 作者有「编辑 / 维护者 / 动态抓取」三个按钮；他人片单只有订阅与显示切换。
6. **回收站** — 资源 Tab 36 万条、影片 Tab 160 条；他人上传的资源「恢复」列显示「—」。
7. **音乐** — 歌曲 52 万条、切专辑（14 万）、切歌手；点歌曲进详情看歌词与资源。
8. **直播** — 77 个频道；点一行展开该频道的源列表。
9. **全局搜索** — 任意页面按 `⌘K`（或点侧栏第一行）→ 未输入时显示「最近看过 / 我上传的 / 我的片单」各 4 条，↑↓ 选中后回车能进对应页面；输入「角斗」→ 影片/音乐/求片三组依次出现（片单无匹配则不显示该组）；↑↓ 移动、Enter 打开详情、Esc 关闭；每组底部「查看全部」跳到对应列表页并带上关键词。
10. **账号** — 资料页权限四项（观影/上传/下载/槽位）、已登录设备列表；「客户端登录」里的访问令牌可显示并复制，用于网页之外的播放器与脚本；邀请页名额显示实际数字（当前 1）。
11. **榜单** — 五个 Tab：萝卜 / 上传量 / 签到各 30 条；「正在播放」显示最近 3 分钟在看的人（片名、季集、倍速、客户端）；「直播」通常为空，空态显示「还没有数据」。
12. **投票** — 「查看结果」输 `2`（元宵投票）→ 每项票数与占比 + 228 人的投票明细；结果接口一次返回全部人，界面按 20/页分。
13. **抽奖** — 「中奖名单」输一个不存在的 ID（如 `abc`）→ 显示「没有取到数据 / 请求失败（404）」，说明错误态正常。

## B. 写（会产生真实副作用，按需选做）

13. **签到** — 概览点「签到」→ toast 提示 +N，卡片变「今天已签」。重复点应被禁用。
14. **修改笔名** — 账号页改名 → 保存 → 刷新后侧栏和页头都变。
15. **收藏一首歌** — 音乐详情点收藏 → toast；再点一次应切换。
16. **加片单再移出** — 片单详情「添加影片」搜一部 → 加入 → 出现在列表 → 移出（确认框）。
17. **认领求片** — 求片页对「求片中」的行点认领 → toast + 状态变「已认领」，行内出现「去上传」。
18. **商品上下架** — 商城点「下架」→ 状态变已下架；再点「上架」恢复。
19. **求片详情** — 求片页任意行点「详情」→ 弹窗显示悬赏、求片人数、认领人与悬赏记录（谁给过胡萝卜）。
20. **片单订阅用户** — 自己的片单详情，点订阅数 → 弹窗列出谁订了、付了多少、到期日。
21. **清空片单内容** — 自己的片单详情点「清空」→ 确认框写明「会把里面的 N 部影片全部移除」，取消不应有副作用。
22. **退出邀请关系** — 账号 → 邀请 → 「退出邀请关系」有二次确认；**这会真的退出**，只在确定要退出时点。

## C. 需要留意的失败点

| 现象 | 可能原因 |
|---|---|
| 某页一直骨架屏 | 该接口慢（ban/list 5–11s、stats 11s），或返回 422 |
| 操作后没反应、也没 toast | 该写操作没有 onSuccess 文案 |
| 数字显示 0 但实际有数据 | 布尔参数没按 1/0 传（已全局修，复现即为遗留点） |
| 图片大面积空白 | `image.theotherdb.org` 在部分网络不可达 |

## D. 已知不可用（不是 bug）

- **用户详情的余额/观影/注册时间**：`/api/pay/getUserInfo` 需要服务商身份，当前账号 403。
- **影院（reel）**：6 个接口是客户端播放器的「随机放映」链路（开一次放映 → 挑版本 →
  上报进度），后台没有对应动作，所以不做界面。详见 `docs/api-coverage.md`。
