## 未修（按价值/成本排序的待办）

**P0 · 影响可用性**
1. 首页没有待办区：待发货、待审店铺、失败上传、异常源都不在首屏；KPI 卡片不可点。
2. 「用户」维度整体缺失：没有 `/users/:id`，订单/求片/封禁/邀请里的 user_id 不可点，客服链路断。
3. 回收站不存在，但删除资源/影片的文案曾承诺可恢复（文案已改，功能仍缺）。
4. 25 处写操作只有 `onSuccess` 没有失败提示；14 处只说「失败」，不讲原因与下一步。
5. 权限不足态 0/16：`is_can_edit` 只隐藏按钮，从不解释为什么不能操作。

**P1 · 体验**
6. 三条主链路止于 toast：上传入库完成、求片认领、订单发货后都没有「下一步去哪」。
7. 89 个端点无界面入口（如 `mediaApi.move` 传错集只能删了重传再扣胡萝卜、`shopApi.deleteProduct` 商品删不掉、`watchApi.remove` 260 个片单删不掉）。
8. 危险操作位置错位：页头「删除/同步/返回」等权重；「删除订单」藏在备注弹窗、「删除资源」藏在重命名弹窗。
9. 窄屏 `.card` 内的表格仍会被裁（详情页操作列）。
10. 排序表头删掉后，列表没有排序能力——需要时按接口 `sort_by/sort_order` 真做。

**P1 · 动效（按 motion.md 的 6 条清单）**
11. 已加：路由淡入、Modal/Confirm 出现、toast 出场。待加：加载→内容切换、行内写操作反馈、侧栏账号菜单。
