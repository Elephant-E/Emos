## 2. 重点三问

### 2.1 删除按钮变红，表格是否过吵？——**在 15 行时会变成"红色竖栏"，建议分档**

实测（`r6-live2.png`）：`/live` **15 行 / 15 个 `.btn--danger-text`**，右边缘形成一条连续的砖红竖列；`/watchlists` 20 行里 6 个（自己的片单）。

判断：**不至于"刺眼"，但确实抢了内容**。
- 红色的饱和度是克制的（`--c-red #f2704a`，12.5px），单看一格很轻；
- 问题在**累加**：一列 15 个同色同位置的强调，视觉上等价于"这一列是最重要的"，而实际上每行最重要的动作是"点开看源"。直播页现在**没有任何其他有色元素**（没有状态徽标），红色成了唯一色彩 → 全表最显眼的东西是删除。
- 对比：`/media/:id` 顶栏 1 个红删除（`r6-video-detail.png`）观感很好——**孤立的危险动作用红是对的，成列的危险动作用红是噪音**。

建议（二选一，成本都低）：
- **A（推荐）**：表格内危险动作恢复"静止 `--fg-4`、hover `--c-red`"，只有**非表格场景**（详情页顶栏、弹层 footer）保持静止红；
- **B**：保留红，但把表格内降到 `#c9553a` 并去掉字重暗示，同时在操作列左侧加 1px `--line-soft` 竖分隔，让红色"被框住"。

### 2.2 `.is-stale` 变暗是否影响正常使用？——**变暗的语义对，但参数过狠**

`components.css:1021-1025`：
```css
.is-stale { opacity: .45; transition: opacity 120ms; pointer-events: none; }
```
实测对比度（卡片底 `#171614`，含 0.45 不透明度）：

| 文本 | 正常 | stale |
|---|---|---|
| `--fg` #f2f1ee | 16.0:1 | **4.15:1**（勉强过 4.5 线的下沿） |
| `--fg-2` #b6b4ae | 8.7:1 | **2.75:1**（不可读） |
| `--fg-3` #8f8d86 | 5.4:1 | **2.10:1**（不可读） |

两个问题：
1. **可读性**：切换筛选时表格里 60% 的文字（副标题、时间、数字列都是 fg-2/fg-3）掉到 2–3:1，属于"暂时不可读"。用户在这个窗口里**没法核对旧数据**，而 stale 态的存在意义恰恰是"让你先看着旧的"。
2. **交互冻结**：`pointer-events: none` 让行点击、勾选、行内按钮在**数据到达前全部失效**。这台实例 `/api/user/stats/video/history` 实测 11s、`/api/ban/list` 5–11s —— 在慢接口上等于"表格装死十几秒"，用户会以为页面卡了。

建议：`opacity: .45` → **`.7`**（fg-3 约 3.4:1），**删掉 `pointer-events: none`**（改为保留交互 + cursor: progress），或者更彻底：保留 100% 不透明，改在表格顶部加一条 2px 的不确定进度条 + 标题右侧一个小 spinner。

### 2.3 季集新布局在真实长番上的表现——**成立，但丢了"扫读"**

实测（`r6-video-detail.png`，`金色光芒`，共 1 季 25 集）：下拉「第 1 季（25 集）」+ 5 列数字网格（01–25），`.ep-grid { max-height: 186px; overflow-y: auto }`（`components.css:1028-1038`）。

- **长番安全性 ✓**：`max-height` 固定 + 内部滚动，1000 集也不会撑开页面，这是上一版（逐条列表）没有的优势。
- **丢了什么**：上一版每行有「标题 · 时长 · N 资源 · N 字幕」，现在网格里只有两位数；要判断"哪一集有资源"必须逐个点。目前只在选中集下方给一行概要（「第 1 集 / 2024-08-14 · — · 1 资源 · 0 字幕」）。
- **建议（一行 CSS + 一个 data 字段）**：给 chip 加一个小圆点表示"该集有资源"（`ep.medias_count > 0`），或把 chip 的 `title` 里已有的信息提一个到视觉上——这能把"扫读"还回来，且不增加高度。

## 5. 只改 5 处

**① 三处裸 `<img>` 换成 `<Poster>`**（`WatchlistsView.tsx:136`、`WatchlistDetailView.tsx:169`、`:249`）
3 行改动，消掉实测的 6 张裂图，把"图片统一"这套补完。

**② 恢复三处权限说明，并统一落点**（直播 / 线路 / 回收站）
一行 `.card-note` 放在表格上方、与表头同左对齐：「显示「—」的是他人创建的内容，只能查看」。这是 R2，也是 SPEC §8 的硬要求——尤其直播页现在 15 行红删除需要它来解释语境。

**③ 表格内危险动作改为「静止灰、hover 红」**（`components.css` 危险色规则）
详情页顶栏/弹层 footer 保持静止红（那里观感很好），只有 `.table` 内回到 `--fg-4` → hover `--c-red`。直接把"15 行红竖栏"消掉，且不需要新增类。

**④ `.is-stale` 放宽**：`opacity: .45 → .7`，删 `pointer-events: none`
修掉"切换筛选时表格不可读且不可点 5–11 秒"的可用性问题（§2.2）。

**⑤ 收尾一致性三小刀**：片单/求片/悄悄话删标题计数；片单隐藏「作者/操作」两个全空列（或把作者移进副标题）；订单/求片空态各补一句下一步
